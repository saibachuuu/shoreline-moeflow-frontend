# 站点管理员身份管理

- 用户列表中的“设为管理员／取消管理员”只对后端返回 `can_manage_site_admins=true` 且仍为站点管理员的当前用户显示。
- 能力由后端根据当前 `ADMIN_EMAIL` 及账号状态判断，不把环境变量邮箱打包到前端，也不根据用户列表中的邮箱自行判断站长。
- 普通管理员保留其他管理操作；旧后端未返回能力字段时默认隐藏身份变更入口。
- 切换 token／账号、降权时清除能力；站长在当前页面取消自身管理员身份后立即更新前端状态。
- 前端仅控制显隐，后端 `PUT /v1/admin/admin-status` 强制验证实际资格，防止绕过 UI。
- 此改动不实现通知系统。通知计划已明确：未来所有有效站点管理员均可发送站点通知，不要求站长身份。
- 按“其他不变”的要求，重置密码等原有高权限操作未一并限制；完整站长账号隔离不在这次修复范围内。

后端详细规则与安全边界见 `moeflow-backend/docs/site-admin-management.md`；完整通知设计见后端 `docs/notification-system-plan.md`，仍待审查。
